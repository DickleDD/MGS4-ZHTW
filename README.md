# MGS4 PC 繁體中文化

《METAL GEAR SOLID 4: Guns of the Patriots - Master Collection Version》PC 版非官方繁體中文化。

## 目前版本

Beta 0.1.3

## 中文化內容

- 劇情過場字幕
- Movie 字幕
- Codec 對話
- 遊戲內即時語音字幕
- 武器、道具與教學說明
- 保留遊戲原本經過設計的英文 UI
- 以日文語音／Japanese 語系為基礎

## 安裝需求

需要自行擁有正版 MGS4 PC 版。

本中文化目前仍處於 Beta 階段，歡迎協助回報漏翻、缺字、字幕過長、錯譯與其他問題。

## Bug 回報

請使用 GitHub Issues 回報問題。
